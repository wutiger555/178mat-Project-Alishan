# 試行工具包

這裡是**真的要開始做**時會用到的東西。PDF 可以直接列印、用手寫填；Excel 可以用電腦填，也可以印出來。

| 檔案 | 什麼時候用 | 誰用 |
|---|---|---|
| [00-第一週行動清單.pdf](00-第一週行動清單.pdf) | 開始的第一天：第一週的 5 件事，加上第 2–4 週的待辦 | 提案人、董事長 |
| [01-第0階段採購清單.xlsx](01-第0階段採購清單.xlsx) | 下單零件時。三個工作表分別是第 0、1、2 階段；可以勾選「已買」、填實際花費，小計會自動算 | 提案人 |
| [02-既有案場盤點表.xlsx](02-既有案場盤點表.xlsx) | 找試點客戶時。把過去施工過的案場整理進來，依「試點適合度」挑出 5–8 個 | 提案人、業務、董事長 |
| [03-試點合作協議範本.pdf](03-試點合作協議範本.pdf) | 跟試點客戶談定時。一頁版，**正式使用前請律師審閱** | 董事長 |
| [04-拜訪用一頁簡介.pdf](04-拜訪用一頁簡介.pdf) | 拜訪物業公司、建商、管委會時留給對方 | 董事長、業務 |
| [05-胎壓計工廠訪談單.pdf](05-胎壓計工廠訪談單.pdf) | 去親戚的胎壓計工廠時帶著，邊談邊寫 | 董事長、提案人 |
| [06-清坑秤砂與試點紀錄表.xlsx](06-清坑秤砂與試點紀錄表.xlsx) | 試點期間。每次清坑秤砂、每次警報或事件都記一筆；另有「計步驗證」工作表 | 施工班、清潔人員、提案人 |
| [07-每週進度報告範本.pdf](07-每週進度報告範本.pdf) | 每週五交給董事長的一頁報告 | 提案人 |
| [08-決定點檢核表.pdf](08-決定點檢核表.pdf) | 第 4 週、第 13 週、第 12 個月的「要不要繼續」決定 | 董事長 |

## 建議的使用順序

1. **第 1 天**：印 00，照著做。
2. **第 1 週**：開始填 01（採購）和 02（案場盤點）；帶 05 去胎壓計工廠。
3. **第 2–4 週**：帶 04 拜訪 1–2 家建商或物業公司；每週五交 07。
4. **第 4 週**：用 06 的「計步驗證」算出誤差，填 08 的決定點①，由董事長決定。
5. **試點開始後**：用 03 簽約；每次清坑、每次事件都記在 06。
