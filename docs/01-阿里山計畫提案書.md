# Project Alishan 阿里山計畫
### 易潔寶® 178mat 轉型提案：從「賣地墊」到「賣一個乾淨、安全、有數據可以證明的入口」

> 給：董事長（爸爸）
> 版本：2026-09 草案
> 互動版：`dist/alishan-demo.html`（雙擊開啟，不需要網路）

---

## 一句話

把 IoT 感測做進我們最熟悉的玉山 ES302 鋁合金除泥地墊，再加上一個每月收費的服務「Alishan Care」。地墊照樣賣，但從此每個月都有經常性收入，而且每個月都跟客戶保持接觸。

---

## 1. 我們現在在哪裡

- **SINCE 2002**：台灣最早自製鋁合金除泥地墊的廠商之一。2004 年設廠量產，2005 年註冊「易潔寶®」。
- **產品系列用台灣的山命名**：玉山 ES302（主力）、雪山 SM305、象山 SS103（1 cm 平鋪）。
- **ES302 規格**：6063-T5 鋁擠型，寬 30 mm、高 18 mm；墊高 23 mm、凹槽 20 mm。SGS 試驗抗壓 15,000 kgf。
- **案場**：桃園機場第一、二航廈、林口長庚質子中心、中國醫大、奇美博物館、海科館、多座科技廠辦、阿里山飯店、環球購物中心；建商有遠雄、冠德、國建、鄉林、總太、麗寶等。官網上有 400+ 篇施工案例。

**老實說，我們的弱點：**
1. 營收幾乎都是一次性工程款，做完就結束。
2. 客戶用了 10–15 年才想到換毯，中間我們跟客戶完全沒有聯繫。
3. 數位能見度低：官網是 Blogger，沒有經營電商和社群。
4. 鋁條地墊很容易被拿來比價。

**關鍵發現：** 我們已經有訂閱業務的種子，就是「舊毯換新」。只是現在都是客戶想到才打來，阿里山計畫要讓數據告訴我們「什麼時候該去」。

## 2. 市場在變

- 85% 的室內髒污是從鞋底帶進來的（ISSA 等產業研究常引用的數字）。
- 清潔人員時薪 NT$200–250，都會區全職月薪約 2.8–4 萬，而且越來越難找人。
- WELL 和 LEED 都要求入口防塵系統在行進方向至少 3 m，WELL 另外要求要有維護計畫。
- 2024 年版智慧建築標章：維運管理、智慧創新等指標都有加分空間。

客戶問的問題變了：以前問「一米多少錢」，現在問「能不能證明有每週維護？下雨天會不會有人滑倒？能不能少派一個人巡邏？」

## 3. 產品：易潔寶 Smart（名稱建議，由爸爸決定）

| 零件 | 做法 |
|---|---|
| 踩踏偵測 | 把 2 條 PVC 避震底座換成**壓電感測底座條**。被踩到時自己會產生訊號，可以直接喚醒模組，不用一直耗電 |
| 積砂量 | 新案：凹槽多挖 5 mm，四角放扁平荷重元，每小時量一次總重；舊案：邊框角落裝 ToF 測積砂高度 |
| 濕度／積水 | 凹槽邊的溫濕度感測器＋積水電極 |
| 模組艙 | 放在實心鋁邊框的端部，裡面有電池、MCU、無線，灌膠密封；上蓋是非金屬天線窗，跟地坪齊平 |
| 無線 | Sub-GHz 或 BLE 傳到大樓閘道器（插電，一棟一台，走 4G 或網路線）。**不靠大樓 Wi-Fi** |
| 通知 | LINE 官方帳號（Messaging API）。舊提案用的 LINE Notify 已在 2025/3/31 停止服務 |

**為什麼這樣設計：**
- 別人的智慧地墊只會數人頭；我們的結構下面有凹槽，所以**可以直接量到積砂**，這是別人沒有的優勢。
- 400+ 個既有案場都能用「換底座條」的方式改裝，第一批客戶就在我們自己的名單裡。

## 4. 它怎麼工作（互動版第 5 章可以直接看）

1. 人走過地墊 → 壓電條計數，雲端累積人流。
2. 下雨天人流大 → 濕度上升 → LINE 通知物管「請放小心地滑警示牌」。
3. 凹槽積砂到 70% → 自動開清潔工單 → 清潔人員在 LINE 上按「我來處理」「完成回報」。
4. 完成後數據歸零，寫進維護紀錄，每月自動產生 ESG／WELL 報表。
5. 夜間 23:00–06:00 保全模式：有人踩到就發入侵警報。
6. 毯條依累計踩踏次數預測壽命，快到的時候 Alishan Care 會主動排程更換。

## 6. 財務試算（保守預設值；互動版可以自己調）

預設假設：第一年新增 20 個入口，每年新增數 ×2；月費 NT$2,500；平均通路分潤 10%；服務成本 NT$900；模組加價 NT$18,000，成本 NT$6,500；年續約率 90%；一次性投入 NT$30 萬；年固定成本 NT$60 萬。

| 指標 | 結果 |
|---|---|
| 回本時間 | 約第 25 個月 |
| 三年累計營收 | 約 NT$640 萬 |
| 第三年底年經常性收入 | 約 NT$340 萬（在線約 126 個入口） |
| 三年毛利率 | 約 62% |
| 每入口終身價值 | 約 NT$11.7 萬，約等於傳統一次銷售毛利的 7.8 倍 |

客戶端：每天巡檢入口 16 次、每次 6 分鐘，改成「有需要才去」後減少一半，一年約省 292 小時、NT$5.8 萬人力，扣掉訂閱費還省約 NT$2.8 萬。這還沒算滑倒理賠和認證的價值。

> 這些數字都是假設。第 1、2 階段的任務，就是把它們換成實際量到的數字。詳見 `04-財務模型說明.md`。

## 7. 為什麼是我們、為什麼是現在

1. **產品和案場都在手上**：24 年施工經驗。別人要做，得先學會做鋁合金地墊。
2. **親戚的胎壓計工廠**：壓力感測、電池撐 5–10 年、灌膠密封、要穿過金屬輪框的低功耗無線、車規量產。這些正好是智慧地墊模組需要的能力。
3. **AI 讓小團隊也做得出軟體**：這份互動提案，就是一個人加上 AI 做出來的。
4. **國外已驗證、台灣還是空白**：SensFloor（德）、Scanalytics（美）、Sensing Tex（西）都證明感測地板可行，但沒有人做在重型鋁合金刮泥地墊裡，也沒有人量積砂和毯條磨耗。台灣同業目前都沒有做 IoT。

## 8. 風險與對策

| 風險 | 對策 | 怎麼驗證 |
|---|---|---|
| 訊號被鋁框、混凝土擋住 | 非金屬天線窗、Sub-GHz、閘道器放大廳 | 第 0 階段第一週實測訊號強度 |
| 泥水、清潔劑、踩踏 | 胎壓計等級灌膠 IP68，模組不在踩踏面 | 浸水、沖洗、荷重測試 |
| 電池壽命 | 壓電喚醒、荷重每小時量一次、批次上傳 | 實測平均電流並推算壽命 |
| 分不出人重還是砂重 | 踩踏交給壓電條；荷重只在沒人時量基線；再用 ToF 交叉比對 | 試點時人工秤砂比對 |
| 客戶不買單 | 先找既有好客戶免費試用 3 個月 | 試點轉付費率 ≥ 30% |
| 影響本業 | 分階段小額投入，每一階段都要過關才繼續 | 每月進度報告 |
| LINE 訊息費用 | 只推播重要警報；查詢用回覆訊息，不計入推播額度 | 每入口每月推播 < 10 則 |

### 附：對原提案（docx）的主要修正

| 原提案 | 修正 | 原因 |
|---|---|---|
| LINE Notify 推播 | LINE 官方帳號 Messaging API | LINE Notify 已在 2025/3/31 停止服務 |
| Cintas 式的「租地墊＋每週換洗物流」 | 「監測＋凹槽清潔＋毯條更換」訂閱 | 易潔寶是固定安裝的鋁合金地墊，會消耗的是毯條和凹槽積砂，不是整塊地墊 |

| ESP32 直接連大樓 Wi-Fi | Sub-GHz／BLE 傳到閘道器，或用 NB-IoT | 大廳 Wi-Fi 常常不能用；鋁框和混凝土會擋訊號 |
| 財務段有缺字與矛盾（「NT54,000」「NT1,500 內」） | 重新建立可以調整的試算模型 | 數字必須經得起推敲 |
