# Project Alishan 阿里山計畫

易潔寶® 178mat 轉型提案：IoT 智慧除泥地墊、Alishan Care 訂閱服務，並附上可以互動的 3D 展示。

## 列印版

**`dist/阿里山計畫提案書.pdf`**：A4、34 頁，可以直接列印。內容有封面、一頁摘要、12 章（含感測器、90 天計畫、逐項預算、銷售、財務）和 4 個附錄，並附上 3D 截圖。重新產生的方式：`cd print && npm install && npm run capture && npm run pdf`（數字直接讀網頁用的同一份資料）。

## 給爸爸看：怎麼打開

**`dist/alishan-demo.html`** 是一個單一檔案，所有程式和 3D 都包在裡面，**不需要網路**。

| 裝置 | 做法 |
|---|---|
| 電腦（最推薦） | 下載檔案後雙擊，用 Chrome、Edge 或 Safari 開啟。可以接電視或投影機 |
| iPad／平板 | 用 AirDrop 或 Email 傳過去，在「檔案」App 裡用瀏覽器開啟。LINE 內建的預覽不會執行 3D |
| 想要一個網址 | 把檔案拖到 [Netlify Drop](https://app.netlify.com/drop)，會得到一個只有知道網址的人才看得到的連結（檔案會上傳到外部服務，請自行評估） |

**簡報操作**：右上角「▶ 簡報模式」會進入全螢幕；`←` `→` 翻頁，`F` 切換全螢幕。3D 模型可以用滑鼠拖曳旋轉、滾輪縮放。

## 開發

```bash
cd web
npm install
npm run dev     # 開發伺服器
npm test        # 財務模型與模擬引擎的單元測試
npm run build   # 輸出 ../dist/alishan-demo.html
```

- `web/src/mat/`：參數化地墊模型（`builder.js` 的尺寸都來自 ES302 規格表）、程式產生的面材紋理
- `web/src/sim/engine.js`：模擬引擎（人流、積砂、濕度、毯條磨耗、工單）。參數在 `SIM_CONFIG`，第 0 階段量到的真實數字要填回這裡
- `web/src/calc/roi.js`：財務模型
- `web/src/scene/`：three.js 場景（產品展示、大樓入口）
- `web/src/ui/`：儀表板、LINE 手機畫面、圖表、試算器

> 模擬與財務數字都是示意假設，不代表實際營運數據。
