# Project Alishan 阿里山計畫

**易潔寶® 178mat 的轉型計畫：把 IoT 感測做進我們最熟悉的玉山 ES302 除泥地墊，再加上每月收費的 Alishan Care 服務。**

地墊照樣賣；從此每個月都有經常性收入，也每個月都跟客戶保持接觸。

---

## 30 秒看懂

| | |
|---|---|
| **要做什麼** | 在地墊裡換上幾條「壓電感測底座條」、凹槽放兩片電極、邊框旁加一個模組艙。踩踏面外觀不變，舊案場約 1 小時就能改裝 |
| **能做到什麼** | 算人流與進出方向；推估凹槽積砂，該清時用 LINE 通知；雨天濕滑提醒；夜間入侵警報；毯條快磨完時主動安排更換；每月產出維護報表 |
| **第一步** | 4 週，約 **NT$1.2–1.8 萬**，做出一片「人踩上去，手機就收到 LINE」的原型。最壞的情況，就是損失這筆錢 |
| **第一年** | 三個階段合計約 NT$35–93 萬；申請 SBIR（政府補一半）後，公司自付約 NT$17–46 萬 |
| **保守試算** | 約第 25 個月回本；第三年底年經常性收入約 NT$340 萬 |

1. **同意啟動第 0 階段**：4 週、約 NT$1.2–1.8 萬。

## 誠實說明

- 模擬、財務試算裡的數字都是**有來源或推算的假設**，要在第 0、1 階段換成實際量到的數字。
- 價格是 2026 年 9 月查到的台灣通路價；標「估計」的項目，下單前要再詢價。
- 積砂量是最難直接量的一項：先用「人次 × 雨量」模型，加上每次清坑秤砂來校正。

<details>
<summary><b>給開發者：怎麼重新產生這些檔案</b></summary>

需要 Node.js 22 以上；PDF 需要 Playwright（Chromium）；Excel 需要 Python 3 與 `openpyxl`。

```bash
# 互動版（輸出 dist/alishan-demo.html，單一檔案、可離線）
cd web && npm install
npm run dev      # 開發伺服器
npm test         # 財務模型、預算、模擬引擎的單元測試
npm run build

# 列印版提案書（輸出 dist/阿里山計畫提案書.pdf）
cd ../print && npm install
npm run capture  # 從互動版截 3D 圖（軟體繪圖，約 8 分鐘）
npm run pdf

# 試行工具包（輸出 試行工具包/*.pdf、*.xlsx）
npm run kit      # 需要 pip install openpyxl
```

- 預算：`web/src/calc/budget.js`；財務模型：`web/src/calc/roi.js`；感測器說明：`web/src/scene/sensorData.js`。網頁、PDF 和工具包都讀這幾份資料，改一處就好。
- 模擬參數：`web/src/sim/engine.js` 的 `SIM_CONFIG`；第 0 階段量到的真實數字要填回這裡。
- 3D 地墊模型：`web/src/mat/builder.js`，尺寸來自 ES302 規格表與 4-BLOCK 施工大樣圖。

</details>
